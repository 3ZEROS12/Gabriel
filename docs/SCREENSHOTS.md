# Screenshot & Demo Recording Guide

This document outlines the key scenarios that should be captured in `demo.gif` or static screenshots for the README and project showcase.

## 1. Mission Control (Multi-Agent Grid)
- **Action**: Open multiple terminals and run different agents (e.g., one running Antigravity, one running Claude Code).
- **Focus**: Show the Gabriel UI dynamically updating in a split-grid view, tracking both agents concurrently without interference.

## 2. Knowledge Base Proactive Recommendation
- **Action**: Simulate a known error occurring in the terminal.
- **Focus**: Capture the exact moment the "Knowledge Base Recommendation" toast notification slides in at the bottom/top of the screen.

## 3. UI Interactions & Polishing
- **Action**: Click through the Sidebar (Control Center, Agent Radar, Knowledge Base, Settings).
- **Focus**: Demonstrate the smooth transitions, dark mode aesthetics (Cyber-Dark Edition), and the active telemetry pulse in the Agent Radar.

## 4. Feedback Flow
- **Action**: Click the "Feedback" button, type a brief issue, and click "Preview & Submit".
- **Focus**: Show the redaction of secrets in the preview modal before confirming submission.
